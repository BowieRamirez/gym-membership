Theme Member, Windows

1. Member Messages (Windows; the coach's page is the same with "Trainees" instead of "Coach")

Announcements sits pinned above the tabs, for members and coaches, with its unread count. It opens like any conversation but has no box to type in.

The tabs are Coach and Gym (was "Staff"). The Gym tab starts with Write to: Front desk, Admin or System admin. Each is its own conversation; the Front desk one is always there, the others appear once you write. Nobody sees who on the team answered, as today.

A time request, an invitation and every answer appear in the coach chat by themselves, in the name of whoever acted, as a framed message with Open Time requests, where the buttons stay.

3. Staff Messages: the inbox shows which queue (Windows only)

Staff keep Open, Mine and Closed. A conversation to Admin or System admin carries a chip saying so; the Front desk ones carry none. Front desk staff see only Front desk; Admin sees Front desk and Admin; System admin sees all three.

4. Announcements page (Admin and System admin; Windows only)

A new menu item next to Messages. Write once, choose who it's for, post. Everyone chosen gets it in Announcements and a notification. Posted announcements can't be edited or removed (they've already been read).
